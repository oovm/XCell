# XCell 模板语法修复 - 实施计划

## [ ] 任务 1：检查所有模板文件的语法
- **优先级**：P0
- **依赖**：无
- **描述**：
  - 检查所有模板文件，确认它们使用的是正确的 dejavu 语法。
  - 特别关注变量输出、条件判断和循环语句的语法。
- **验收标准**：AC-1
- **测试要求**：
  - `programmatic` TR-1.1：所有模板文件的语法都符合 dejavu 语法规则。
- **注意**：需要检查所有 .dejavu 文件，包括 TypeScript 和 C# 模板。

## [ ] 任务 2：修复模板文件中的语法错误
- **优先级**：P0
- **依赖**：任务 1
- **描述**：
  - 将所有模板文件中的 Jinja 语法转换为正确的 dejavu 语法。
  - 特别注意变量输出语法（从 `{{ variable }}` 或 `<%= variable %>` 改为 `<% variable %>`）。
  - 特别注意循环语法（从 `{% for item in list %}` 改为 `<% loop item in list %>`）。
- **验收标准**：AC-1, AC-2
- **测试要求**：
  - `programmatic` TR-2.1：所有模板文件的语法都已修复为 dejavu 语法。
  - `programmatic` TR-2.2：模板渲染时能够正确解析所有变量和控制流语句。
- **注意**：需要确保修复后的语法与 dejavu 模板引擎的要求一致。
