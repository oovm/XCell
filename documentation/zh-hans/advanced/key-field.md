# 主键字段

主键是表中用于唯一标识每一行数据的字段。

## 默认规则

- **第一列自动视为主键**，无需额外标记

## 显式标记

可以在字段名前添加 `@` 或 `@@` 标记：

| 标记 | 说明 |
| ---- | ---- |
| `@字段名` 或 `字段名 @unique` | 唯一字段，值不能重复 |
| `@@字段名` 或 `字段名 @primary` | 主键字段，值唯一且作为主键 |

### 示例

| @dict | 名称 | 等级 |
| ----- | ---- | ---- |
| @@user_id | name | @email |
| string | string | string |
| user_001 | 张三 | zhangsan@example.com |
| user_002 | 李四 | lisi@example.com |

- `@@user_id` - 主键字段
- `@email` - 唯一字段（不能重复，但不是主键）

## 复合键

当多个字段组合起来必须唯一时，可以使用复合键。在左上角第一格添加 `@unique` 标记：

| @unique | 职业 | 等级 |
| ------- | ---- | ---- |
| @dict | class | level |
| string | string | i32 |
| warrior_001 | warrior | 10 |
| warrior_002 | warrior | 20 |
| mage_001 | mage | 10 |

上述示例中，`职业 + 等级` 组合必须唯一，但单独的职业或等级可以重复。

## 主键要求

- 主键值必须唯一
- 主键值不能为空
- 每张表只能有一个主键

## 主键类型

| 表格类型 | 主键类型 |
| -------- | -------- |
| dict 表 | 字符串 |
| list 表 | 整数 |

> language 表结构固定，没有主键概念。

## 示例

### dict 表主键

| @dict | 名称 |
| ----- | ---- |
| @@item_id | name |
| string | string |
| sword_001 | 铁剑 |
| sword_002 | 精钢剑 |

### list 表主键

| @list | 名称 |
| ----- | ---- |
| @@id | name |
| i32 | string |
| 1 | 史莱姆 |
| 2 | 哥布林 |
