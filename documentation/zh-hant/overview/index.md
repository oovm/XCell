# XCell 功能特性

## 資料表格類型

| 類型 | 说明 |
| ---- | ---- |
| dict 資料表 | 字元串主鍵，最常用的設定形式 |
| list 資料表 | 整数主鍵，按顺序存取 |
| enum 資料表 | 列舉類型，附加额外資料 |
| class 資料表 | 全局設定類別，單例模式 |
| language 資料表 | 多語言支援 |

## 程式碼生成目标

| 目标 | 語言/格式 | 狀態 |
| ---- | --------- | ---- |
| Unity | C# | ✅ 已導现 |
| Cocos | TypeScript + JSON | ✅ 已導现 |
| JSON | JSON 資料 | ✅ 已導现 |
| Binary | 二進位元資料 | ✅ 已導现 |
| Dejavu | 範本引擎 | ✅ 已導现 |

## 類型系統

### 基本類型

| 類型 | 说明 |
| ---- | ---- |
| `bool` | 布屬值 |
| `i8`, `i16`, `i32`, `i64` | 有符後整数 |
| `u8`, `u16`, `u32`, `u64` | 无符後整数 |
| `f32`, `f64` | 浮点数 |
| `string` | 字元串 |

### 奧合類型

| 類型 | 说明 |
| ---- | ---- |
| `[T]` | 勁态陣列 |
| `[T; N]` | 静态陣列 |
| `Vec<T>` | 向量/串列 |
| `vec2`, `vec3`, `vec4` | 向量類型 |
| `HashMap<K, V>` | 字典類型 |

### 特殊類型

| 類型 | 说明 |
| ---- | ---- |
| `color` | 顏色類型 |
| `datetime`, `time`, `date` | 时间類型 |
| `&T` | 參照類型 |

## 合資料表功能

- **命名约定**：下則线命名自勁合併，如 `Item_Weapon` + `Item_Armor` → `Item`
- **合併规創**：相同结构自勁合併，相同 ID 报错
- **保留資料表名**：`Language` 為保留資料表名

## 設定系統

- **專案設定**：`XCell.toml` 專案根目錄
- **資料表格設定**：同名 `.toml` 檔案
- **行對應**：支援旧資料表迁移

## 架构

```
xcell-provider (資料表格读農)
    ↓
xcell-analyzer (資料表格分析)
    ↓
xcell-generator (程式碼生成)
    ↓
xcell (CLI 工具)
```

| 模組 | 功能 |
| ---- | ---- |

| xcell-parser | 语法剖析器 |
| xcell-analyzer | 資料表格分析器 |

| xcell-generator | 程式碼生成器 |
| xcell-plugin | 外掛程式系統 |
