## About XCell

XCell is a powerful configuration table management tool designed specifically for game development and projects requiring complex data management. It is developed using the Rust programming language, providing high-performance, type-safe data management solutions.

### Supported Game Engines and Programming Languages

XCell supports multiple game engines and programming languages, including but not limited to:
- **Unity** (C#) - Full built-in support
- **Cocos Creator** (TypeScript/JavaScript/Lua)
- **Godot** (GDScript/C#)
- **Unreal Engine** (C++)
- **Custom Engines** (any language)

### Supported Programming Languages

- C#, C++, Rust
- Python, Lua, JavaScript/TypeScript
- And more...

No matter what game engine or programming language you use, XCell can provide you with an excellent configuration table management solution!
