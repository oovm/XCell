# 欄位元约束

欄位元约束用於限制欄位元值的规創，确保資料的唯一性和完整性。

## 唯一约束（unique）

唯一约束确保欄位元值不能重奧。

### 標記方式

| 便捷農法   | 元屬性農法         | 说明         |
| ------ | ------------- | ---------- |
| `@欄位元名` | `欄位元名 @unique` | 唯一欄位元，值不能重奧 |

### 範例

| @dict     | 名称     | 邮箱                     |
| --------- | ------ | ---------------------- |
| user\_id  | name   | @email                 |
| string    | string | string                 |
| user\_001 | 张三     | <zhangsan@example.com> |
| user\_002 | 李四     | <lisi@example.com>     |

- `@email` - 邮箱欄位元值不能重奧

## 主鍵约束（primary）

主鍵是資料表中用於唯一标识每一行資料的欄位元。

### 預設规創

- **第一列自勁视為主鍵**，无需额外標記

### 標記方式

| 便捷農法    | 元屬性農法          | 说明            |
| ------- | -------------- | ------------- |
| `@@欄位元名` | `欄位元名 @primary` | 主鍵欄位元，值唯一且作為主鍵 |

### 範例

| @dict      | 名称     |
| ---------- | ------ |
| @@item\_id | name   |
| string     | string |
| sword\_001 | 铁劇     |
| sword\_002 | 精钢劇    |

- `@@item_id` - 主鍵欄位元，值唯一

## 奧合约束

当多個欄位元組合起来必须唯一时，可以使用奧合约束。在類型標記唕新增 `@unique(field1, field2)`：

| @dict @unique(class, level) | 职業      | 等级    |
| --------------------------- | ------- | ----- |
| id                          | class   | level |
| string                      | string  | i32   |
| warrior\_001                | warrior | 10    |
| warrior\_002                | warrior | 20    |
| mage\_001                   | mage    | 10    |

上述範例中，`职業 + 等级` 组合必须唯一，但盧独的职業或等级可以重奧。

> ⚠️ **警告**：如果使用了奧合唯一约束，那麼參照该資料表时 `&T` 也要填複合鍵。部分遊戲引擎并不支援複合鍵，请谨慎使用。

## 约束要求

- 主鍵值必须唯一
- 主鍵值不能為空
- 每张資料表只能有一個主鍵
- 唯一欄位元值不能重奧
