## 表格格式

XCell 采用统一的表格格式，适合各种复杂度的配置表。

### 基本结构

- **直接定义字段**：第一行开始直接定义字段名和数据
- **优点**：结构紧凑，易于编辑和阅读
- **适用场景**：所有配置表，从简单到复杂

### 示例

| id | name | hp |
| -- | ---- | -- |
| 1  | 史莱姆  | 50 |
| 2  | 哥布林  | 80 |
