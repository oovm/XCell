# 数据表生成修复 - 产品需求文档

## 概述
- **摘要**：修复 XCell 工具生成的数据表与原始 CSV 配置表不匹配的问题，确保生成的 Cocos 和 Unity 数据表文件正确反映原始配置表的结构和内容。
- **目的**：解决生成的表与原始表不匹配的问题，确保游戏开发过程中数据的一致性和正确性。
- **目标用户**：使用 XCell 工具生成数据表的游戏开发者。

## 目标
- 确保生成的 Cocos TypeScript 文件正确反映原始 CSV 表的结构和字段
- 确保生成的 Unity C# 文件正确反映原始 CSV 表的结构和字段
- 确保生成的数据表管理器能够正确加载和管理所有原始表数据
- 修复 SLG 和 Galgame 游戏的数据表生成问题

## 非目标（范围外）
- 不修改 XCell 工具的核心代码结构
- 不添加新的生成器类型
- 不修改原始 CSV 配置表的结构

## 背景与上下文
- XCell 工具用于将 CSV 配置表生成游戏引擎可用的数据文件
- 目前生成的表与原始表不匹配，导致游戏开发过程中数据不一致
- 问题影响 SLG 和 Galgame 游戏的开发

## 功能需求
- **FR-1**：生成的 Cocos TypeScript 文件应包含原始 CSV 表中的所有字段
- **FR-2**：生成的 Unity C# 文件应包含原始 CSV 表中的所有字段
- **FR-3**：生成的数据表管理器应包含所有原始表的加载和管理方法
- **FR-4**：生成的文件应正确处理表之间的关联关系

## 非功能需求
- **NFR-1**：生成过程应保持稳定，无错误
- **NFR-2**：生成的代码应符合代码规范，有良好的注释
- **NFR-3**：生成的文件应与原始表结构保持一致

## 约束
- **技术**：使用现有的 XCell 工具和生成器
- **依赖**：依赖于原始 CSV 配置表的结构

## 假设
- 原始 CSV 配置表的结构是正确的
- XCell 工具的核心功能是正常的

## 验收标准

### AC-1：SLG 游戏数据表生成
- **给定**：SLG 游戏的 CSV 配置表（Units.csv, Buildings.csv, Technologies.csv）
- **当**：运行 XCell 生成工具
- **然后**：生成的 Cocos 和 Unity 文件应包含所有原始表的字段
- **验证**：`programmatic`

### AC-2：Galgame 游戏数据表生成
- **给定**：Galgame 游戏的 CSV 配置表（Characters.csv, Scenes.csv, Dialogues.csv）
- **当**：运行 XCell 生成工具
- **然后**：生成的 Cocos 和 Unity 文件应包含所有原始表的字段
- **验证**：`programmatic`

### AC-3：数据表管理器生成
- **给定**：所有 CSV 配置表
- **当**：运行 XCell 生成工具
- **然后**：生成的数据表管理器应包含所有表的加载和管理方法
- **验证**：`programmatic`

### AC-4：代码质量
- **给定**：生成的代码文件
- **当**：检查代码文件
- **然后**：代码应符合规范，有良好的注释
- **验证**：`human-judgment`
