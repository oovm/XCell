# XCell 概述

## 项目概述

XCell 是一个强大的配置表管理工具，专为游戏开发和需要复杂数据管理的项目设计。它允许开发者使用 Excel 等电子表格软件编辑配置数据，并自动将这些数据导出为多种格式，支持各种游戏引擎和编程语言，包括 Unity (C#)、Cocos、Godot、Unreal Engine (C++)、以及 Lua、Python、TypeScript、Rust 等语言。

### XCell 解决的问题

- **数据管理复杂度**：游戏开发中通常需要管理大量配置数据（角色属性、道具信息、关卡设计等），XCell 提供了结构化的方式来组织这些数据
- **多格式导出**：不同的游戏引擎和平台需要不同的数据格式，XCell 支持一键导出多种格式
- **团队协作**：通过电子表格，非技术人员也能参与配置数据的编辑
- **类型安全**：提供严格的数据类型检查，避免在运行时出现类型错误
- **增量更新**：支持文件监听模式，只更新修改过的文件，提高工作效率

## 核心功能详细介绍

### 多种表格类型

XCell 支持五种核心表格类型，每种类型都针对特定的使用场景设计：

#### 1. Class 表
- **用途**：定义结构化的数据类，包含字段定义和数据行
- **特点**：
  - 支持丰富的数据类型（整数、小数、字符串、布尔值、数组、向量、颜色、时间等）
  - 自动生成对应的 C# 类定义
  - 支持字段注释和文档
- **代码位置**：`projects/xcell-core/src/x_table/class/`

#### 2. Dictionary 表
- **用途**：键值对数据存储，支持列表和字典两种形式
- **特点**：
  - XListTable：简单的列表数据
  - XDictTable：键值对字典数据
  - 灵活的键类型支持
- **代码位置**：`projects/xcell-core/src/x_table/dictionary/`

#### 3. Enumerate 表
- **用途**：定义枚举类型和枚举值
- **特点**：
  - 支持枚举值的描述和注释
  - 自动生成 C# 枚举定义
  - 枚举值之间可以建立关联关系
- **代码位置**：`projects/xcell-core/src/x_table/enumerate/`

#### 4. Language 表
- **用途**：多语言文本管理
- **特点**：
  - 支持多种语言的文本存储
  - 语言 ID 管理
  - 便于国际化和本地化
- **代码位置**：`projects/xcell-core/src/x_table/language/`

### 合表功能

XCell 提供强大的表格合并功能，支持两种合并模式：

#### 行合并 (Row Merge)
- 将多个具有相同结构的表格按行合并
- 适用于将分模块编辑的同类型数据合并为一个完整表格
- 例如：将不同团队编辑的道具表合并为一个完整的道具数据库

#### 列合并 (Column Merge)
- 将多个表格按列合并
- 适用于扩展已有表格的字段
- 例如：为多语言系统添加新的语言列

合表规则通过 TOML 配置文件定义，支持灵活的模式匹配和优先级控制。

**代码位置**：`projects/xcell-core/src/config/merge_rules/`

### 导出功能

XCell 支持多种导出格式，满足不同游戏引擎和编程语言的需求：

#### 1. Unity (C#) 导出
- 自动生成强类型的 C# 类
- 包含数据管理器代码
- 支持二进制数据读取
- 使用模板引擎生成代码，易于自定义
- 支持 Unity XLua 集成
- **代码位置**：`projects/xcell-core/src/codegen/unity/`

#### 2. 二进制导出
- 高效的二进制数据格式
- 支持大小端配置
- 快速的加载速度
- 适合所有游戏引擎的生产环境使用
- 可轻松适配 C++、Rust、Python、Lua 等语言的读取器
- **代码位置**：`projects/xcell-core/src/codegen/binary/`

#### 3. XML 导出
- 标准的 DataContract 格式
- 易于调试和查看
- 支持与其他系统集成
- 适用于 Cocos Creator、Godot 等引擎
- **代码位置**：`projects/xcell-core/src/codegen/xml/`

#### 4. JSON 导出
- 通用的 JSON 格式
- 便于 Web 应用和跨平台使用
- 人类可读的格式
- 完美支持 JavaScript/TypeScript、Python、Lua 等语言
- 适用于所有现代游戏引擎

#### 5. 多语言支持
XCell 的架构设计支持扩展到任何编程语言：
- **C++**: 通过自定义代码生成器，适配 Unreal Engine 或自定义引擎
- **Rust**: 直接生成 Rust 结构体和读取器
- **Python**: 生成 Python 数据类和加载器
- **Lua**: 生成 Lua 表格和加载函数
- **TypeScript/JavaScript**: 生成 TypeScript 接口和 JSON 加载器
- **其他语言**: 通过模板引擎轻松扩展

XCell 的模块化架构让你可以为任何游戏引擎和编程语言创建自定义导出器！

### 配置系统

XCell 使用 TOML 配置文件进行项目配置，提供灵活的定制能力：

#### 项目配置 (ProjectConfig)
- 工作目录设置
- 文件包含/排除规则
- 输出目录配置
- 版本管理
- **代码位置**：`projects/xcell-core/src/config/project/`

#### 表格配置 (TableConfig)
- 表格特定的配置选项
- 行模式配置
- **代码位置**：`projects/xcell-core/src/config/table/`

#### 游戏引擎配置
- **Unity 配置 (UnityCodegen)**: C# 命名空间设置、二进制输出配置、代码生成模板路径等
- **其他引擎配置**: 通过模块化架构轻松扩展支持 Cocos、Godot、Unreal 等引擎
- **代码位置**：`projects/xcell-core/src/config/unity/`

## 项目的技术亮点

### 1. Rust 编程语言
- 高性能：编译型语言，执行速度快
- 内存安全：无需垃圾回收，内存管理高效
- 并发安全：天然支持并发编程
- 跨平台：支持 Windows、macOS、Linux

### 2. 模块化架构
- **xcell-core**：核心功能库，包含所有表格处理、代码生成逻辑
- **xcell-types**：数据类型定义和处理
- **xcell-errors**：统一的错误处理系统
- **xcell-cli**：命令行界面
- **xcell-gui**：图形用户界面（基于 Tauri）
- **stream-io**：流式 IO 处理

### 3. 类型系统
- 丰富的内置数据类型
- 自定义类型支持
- 严格的类型检查
- 类型安全的代码生成

### 4. 增量监听模式
- 使用文件系统监听
- 只处理修改过的文件
- 大大提高工作效率
- 适合开发阶段使用

### 5. 模板引擎
- 使用 Askama 模板引擎
- 编译时模板检查
- 易于自定义代码生成
- 支持多种编程语言

## 与其他导表工具相比的优势

### 1. 多种表格类型
- 大多数工具只支持简单的表格结构
- XCell 提供专门为游戏开发设计的多种表格类型
- 每种类型都有优化的处理逻辑

### 2. 强大的合表功能
- 灵活的合并规则配置
- 支持行合并和列合并
- 便于团队协作和模块化开发

### 3. 丰富的导出格式
- 同时支持多种导出格式
- 二进制格式针对性能优化
- C# 代码生成提供类型安全

### 4. 配置灵活
- TOML 配置文件，易于阅读和编辑
- 项目级和表格级配置
- 支持自定义代码生成模板

### 5. GUI 界面
- 提供图形用户界面
- 降低使用门槛
- 适合非技术人员使用

### 6. 开源和可扩展
- 完全开源
- 模块化设计，易于扩展
- 活跃的社区支持

## 总结

XCell 是一个功能强大、设计精良的配置表管理工具，特别适合游戏开发项目。它提供了丰富的表格类型、灵活的合表功能、多种导出格式和完善的配置系统，能够满足各种复杂的数据管理需求。其 Rust 实现保证了高性能和可靠性，而模块化架构则使其易于扩展和定制。

无论是小型独立游戏还是大型 AAA 项目，XCell 都能提供出色的配置表管理解决方案。
