# JSON データフォーマット

JSON は軽量なデータ交換フォーマットで、XCell は設定データを JSON フォーマットでエクスポートすることをサポートしています。

## 型マッピング

| XCell 型 | JSON 型 | 説明 |
|-----------|-----------|------|
| `i8` | `number` | 8ビット符号付き整数 |
| `i16` | `number` | 16ビット符号付き整数 |
| `i32` | `number` | 32ビット符号付き整数 |
| `i64` | `number` | 64ビット符号付き整数 |
| `u8` | `number` | 8ビット符号なし整数 |
| `u16` | `number` | 16ビット符号なし整数 |
| `u32` | `number` | 32ビット符号なし整数 |
| `u64` | `number` | 64ビット符号なし整数 |
| `f32` | `number` | 32ビット浮動小数点数 |
| `f64` | `number` | 64ビット浮動小数点数 |
| `bool` | `boolean` | ブール値 |
| `string` | `string` | 文字列 |
| `array<T>` | `array` | 配列 |
| `map<K, V>` | `object` | マッピング |
| `enum` | `string` | 列挙（文字列形式） |
| `struct` | `object` | 構造体 |

## 統合手順

1. **JSON エクスポートの設定**：XCell 設定で JSON フォーマットエクスポートを有効化
2. **JSON の生成**：XCell を使用して JSON データファイルを生成
3. **JSON の読み込み**：ターゲットプラットフォームで JSON ファイルを読み込み・解析
4. **データの使用**：アプリケーションで解析後のデータを使用

## サンプル JSON

```json
{
  "Player": [
    {
      "id": 1,
      "name": "Player1",
      "level": 10,
      "gold": 1000,
      "is_active": true
    },
    {
      "id": 2,
      "name": "Player2",
      "level": 15,
      "gold": 2000,
      "is_active": true
    }
  ],
  "Item": [
    {
      "id": 1,
      "name": "Sword",
      "damage": 10,
      "price": 100
    }
  ]
}
```

## 注意事項

- JSON の数値型には精度制限がありませんが、一部の言語では精度の問題が発生する可能性があります
- 複雑なデータ構造はネストされた JSON オブジェクトと配列に正しく変換されます
- 列挙値はデフォルトで文字列形式で格納されますが、数値形式に設定することも可能です
- 生成された JSON ファイルはフロントエンドとバックエンドアプリケーションで直接使用できます
