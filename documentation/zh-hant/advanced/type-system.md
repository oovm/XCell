# 類型系統（Type System）

XCell 支援多种資料類型，标准類型采用 Rust 约定，同时相容 C 约定和 C++ 约定。類型不區分大小寫。

## 基本類型

### 整数類型

| 标准寫法  | Unity 约定             | Unreal 约定  | 描述       | 范圍                                         |
| ----- | -------------------- | ---------- | -------- | ------------------------------------------ |
| `i8`  | `char`               | `int8_t`   | 8位有符號整数  | -128 到 127                                 |
| `u8`  | `unsigned char`      | `uint8_t`  | 8位无符號整数  | 0 到 255                                    |
| `i16` | `short`              | `int16_t`  | 16位有符號整数 | -32768 到 32767                             |
| `u16` | `unsigned short`     | `uint16_t` | 16位无符號整数 | 0 到 65535                                  |
| `i32` | `int`                | `int32_t`  | 32位有符號整数 | -2147483648 到 2147483647                   |
| `u32` | `unsigned int`       | `uint32_t` | 32位无符號整数 | 0 到 4294967295                             |
| `i64` | `long long`          | `int64_t`  | 64位有符號整数 | -9223372036854775808 到 9223372036854775807 |
| `u64` | `unsigned long long` | `uint64_t` | 64位无符號整数 | 0 到 18446744073709551615                   |

<br />

### 浮点数類型

| 标准寫法  | C 约定     | C++ 约定   | 描述     | 精度  |
| ----- | -------- | -------- | ------ | --- |
| `f32` | `float`  | `float`  | 32位浮点数 | 單精度 |
| `f64` | `double` | `double` | 64位浮点数 | 雙精度 |

### 布爾類型

| 标准寫法   | C 约定   | C++ 约定 | 描述  | 值                |
| ------ | ------ | ------ | --- | ---------------- |
| `bool` | `bool` | `bool` | 布爾值 | `true` 或 `false` |

### 字元類型

| 标准寫法    | 描述          |
| ------- | ----------- |
| `utf8`  | UTF-8 字元類型  |
| `utf16` | UTF-16 字元類型 |

### 字串類型

| 标准寫法     | 描述                 |
| -------- | ------------------ |
| `string` | 字串類型              |
| `str`    | 字串類型（與 string 等效） |

## 復合類型

### 陣列與向量類型

**不同類型的约定**：

| 标准寫法        | C# 约定            | 描述         |
| ----------- | ---------------- | ---------- |
| `[T]`       | `T[]`            | 動態陣列       |
| `[T; N]`    | `T[N]`           | 静態陣列（固定大小） |
| `Vec<T>`    | `List<T>`        | 向量/串列類型    |
| `vec2<f32>` | `Vector2<float>` | 2D向量       |
| `vec3<f32>` | `Vector3<float>` | 3D向量       |
| `vec4<f32>` | `Vector4<float>` | 4D向量       |

**说明**：

- 動態陣列 `[T]` 和向量 `Vec<T>` 用於儲存可變数量的元素
- 静態陣列 `[T; N]` 用於儲存固定数量的元素，长度在定義时確定
- 特殊向量類型（vec2/vec3/vec4）在圖像编程中常用，Unity 等引擎會有特定的效能最佳化

**範例**：

- `[i32; 5]` - 套件含5個i32元素的静態陣列
- `[string]` - 動態大小的字串陣列
- `Vec<i32>` - 整数向量
- `vec3<f32>` - 3D浮点向量

### 字典類型

**格式**：`HashMap<K, V>` 或 `dict<K, V>`

**範例**：

- `HashMap<string, i32>` - 字串到整数的對應
- `dict<i32, string>` - 整数到字串的對應

### 元組類型

**格式**：`(T1, T2, ...)`

**範例**：

- `(i32, string)` - 套件含整数和字串的元組
- `(f32, f32, bool)` - 套件含兩個浮点数和一個布爾值的元組

## 独一類型與主鍵

**独一類型格式**：

- `@T` - 資料表示该欄位的值在資料表中必须唯一，即資料表中不能有兩行資料在该欄位上有相同的值
- `@@T` - 資料表示该欄位的值在資料表中必须唯一且作為主鍵

**主鍵说明**：

- 主鍵是資料表中用於唯一标识每一行資料的欄位
- 如果資料表中没有使用 `@@T` 显式標記主鍵，那麼資料表的第一列會自動被视為主鍵
- 主鍵值必须唯一且非空，用於在資料表之间建立關联關系

**範例**：

- `@@i32` - 整数類型的主鍵欄位
- `@string` - 字串類型的唯一欄位（非主鍵）

## 自訂類型

### 列舉類型

通过 Enumerate 資料表格定義的列舉類型可以在其他資料表格中使用。

**範例**：

- `QualityType` - 參照列舉資料表中定義的品质類型

### 結構體類型

通过 Class 資料表格定義的結構體類型可以在其他資料表格中使用。

**範例**：

- `Position` - 參照 Class 資料表格中定義的位置結構體

## 類型转换

XCell 支援自動類型转换，例如：

- 整数可以自動转换為浮点数
- 浮点数在需要时可以转换為整数（會截断小数部分）
- 数字可以转换為字串
- 字串可以在适當情況下转换為数字

## 類型驗證

XCell 在剖析資料表格时會进行類型驗證，确保資料符合指定的類型要求。如果類型不匹配，會在編譯时生成錯誤。
